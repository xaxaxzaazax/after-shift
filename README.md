# After Shift

A private, offline-friendly shift and tip tracker. Entries are stored only in the browser's local storage and are not committed to this repository or sent to a server.

## Run locally

Serve this folder with any static web server, then open it in a browser. A local server is required for the service worker and offline support.

## Privacy

The published repository contains only the app's source files. Shift history remains on the device and browser where it was entered.
