THE PROBLEM

Tipped income is a black box.

Millions of U.S. restaurant workers earn a sub-minimum base wage - as low as $2.13/hour federally - plus tips that change every single night. Most track earnings in their heads, in a notes app, or not at all.

Every shiftSales, tips, tip-outs, and hours vary night to night
No paper trailTip-out reports get thrown away; discrepancies go unnoticed

THE SOLUTION

One tap after every shift. Complete clarity.

After Shift turns a photo of the nightly tip-out report into structured earnings data - date, sales, tips, tip-out, and hours - then combines it with the worker's base wage for a true earnings picture.

THE EARNINGS ENGINE

"I made $100 in tips, tipped out $20, and worked 3 hours at $2.13…
so I earned $86.39."

After Shift is the only place that math happens automatically. Each shift snapshots the wage it was worked at - so raises never rewrite history. Weekly, monthly, and yearly views all include base pay, net tips, tip percentages, and true earnings per hour.

TECHNOLOGY & TRUST

Production infrastructure, privacy first.

Live today as an installable web app, architected so the same secure backend powers the native iPhone app next.

Supabase backendPostgres with row-level security - every user can only ever read their own data. Authenticated APIs, versioned migrations.
Server-side AIOpenAI vision runs inside a secured edge function. API keys never touch the client. Per-user daily scan limits control costs.
Full account controlEmail + password auth, password reset, delete-all-data, and permanent account deletion built in - App Store ready.
Human-in-the-loopAI output is always reviewed before saving. Earnings are clearly labeled as estimates - not payroll or tax advice.
